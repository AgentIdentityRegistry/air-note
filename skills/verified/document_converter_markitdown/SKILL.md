# Document Converter (MarkItDown)

Use this skill to convert local documents into Markdown for review, summarization, or ingestion.

## Inputs
- A local file path selected by the user.

## Behavior
- Prompts for file access confirmation.
- Converts supported formats to Markdown.
- Returns the converted Markdown result.

## Safety
- Never execute document macros or scripts.
- Only read files explicitly approved by the user.
