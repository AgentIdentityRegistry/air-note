# Design: Consolidate SuperClaw (BossClaw) into `air-note`

**Date:** 2026-06-08
**Status:** Approved (design) → implementation plan next
**Author:** Peter + Claude (brainstorming session)
**Target repo:** `~/air-note` (`AgentIdentityRegistry/air-note`, PUBLIC)
**Source repo:** `~/SuperClaw` (`ahnkwangwook-oss/bossclaw`)

## Problem

The AIR Note messaging stack and Rust SDK were duplicated across two repos that
have since drifted. The result is two "side tables" instead of one clean build,
and recurring confusion about which copy is canonical.

Evidence gathered this session (disk diff + dependency graph):

- **`agent-bridge-mcp` (JS messaging):** `air-note` has **35 files SuperClaw lacks**
  — the entire recent body of work: receiver daemon (`daemon.mjs`,
  `daemon-sinks.mjs`, `fanout.mjs`), group chat (`rooms.mjs`, `room-ops.mjs` + 9
  room tests), `moderation.mjs`, `peers.mjs`, `consumer-lock.mjs`, and a whole
  `bridge.mjs` + `adapters/` Telegram bridge. SuperClaw's only unique file is
  `.omc` (local tooling junk). **SuperClaw's copy is a stale snapshot.**
- **`crates/air-rs` (Rust):** identical file set; 6 files differ. Every differing
  line is the same cosmetic edit — SuperClaw says `specs/a2a/…` + `bossclaw`,
  air-note says `specs/air/…` + `air-note`. Line counts match exactly
  (47/47, 161/161, 138/138, 259/259, 28/28, 75/75). **The Rust code is
  byte-identical; air-note merely finished the `a2a→air` rename SuperClaw left
  half-done.**
- **Nothing in SuperClaw imports `agent-bridge-mcp`** (grep of `apps/`,
  `packages/`, root `package.json` came back empty) — the stale JS copy is
  orphaned dead weight.
- **The desktop app's only real dependency on the messaging stack is the Rust
  crate:** `apps/desktop/src-tauri/Cargo.toml` →
  `air-rs = { path = "../../../crates/air-rs" }`.

Per the canonical AIR protocol (`air/session-start-protocol`), `~/air-note` is
already designated the single source of truth; `~/SuperClaw` is legacy, kept only
because the desktop app path-depends on `crates/air-rs`.

## Goal

One clean monorepo. `air-note` holds the whole AIR Note world: the Rust SDK, the
messaging stack, **and** the BossClaw reference desktop app. Retire SuperClaw.

## End state

```
air-note/
├─ crates/air-rs/        (existing, canonical) Rust SDK — UNTOUCHED
├─ agent-bridge-mcp/     (existing, canonical) JS messaging — UNTOUCHED
├─ apps/desktop/         NEW — BossClaw Tauri + React desktop app
├─ packages/shared/      NEW — @bossclaw/shared (app dependency)
├─ skills/verified/      NEW — the app's 3 bundled skills
├─ Cargo.toml            members: ["crates/air-rs", "apps/desktop/src-tauri"]
├─ package.json          NEW root — npm workspaces ["apps/*", "packages/*"]
├─ package-lock.json     NEW — regenerated by npm install
├─ tsconfig.base.json    NEW — apps/desktop/tsconfig.json extends ../../tsconfig.base.json
├─ eslint.config.mjs     NEW — carry the app's lint setup
├─ .prettierrc           NEW
├─ .prettierignore       NEW
├─ .github/workflows/    NEW — build.yml + conformance.yml (air-note has none today)
├─ docs/                 existing + this spec
├─ Cargo.lock            regenerated (gains desktop app deps)
├─ LICENSE / README.md   README updated to describe both products
└─ .gitignore            merge SuperClaw's ignores (node_modules, target, dist, etc.)
```

## What moves / drops / wires

### Moves in (clean copy — one "import BossClaw desktop app" commit)
- `apps/desktop/` — the full Tauri app (React frontend in `src/`, Rust backend in
  `src-tauri/`, icons, `.env.example`, `tauri.conf.json`).
- `packages/shared/` — `@bossclaw/shared`; the desktop app depends on it via
  `"@bossclaw/shared": "file:../../packages/shared"`.
- `skills/verified/` — daily_briefing_framework, document_converter_markitdown,
  research_assistant + `registry.json`.
- Root build config the app needs: `tsconfig.base.json` (extended by the app),
  `eslint.config.mjs`, `.prettierrc`, `.prettierignore`.
- `.github/workflows/build.yml` + `conformance.yml`.

### Dropped (air-note already has equal-or-better)
- SuperClaw `crates/air-rs/` — identical code, older `a2a` URLs; air-note's wins.
- SuperClaw `agent-bridge-mcp/` — stale; air-note's is a strict superset.

### Wired
- **Cargo workspace:** air-note `Cargo.toml` members
  `["crates/air-rs"]` → `["crates/air-rs", "apps/desktop/src-tauri"]`.
  Both root manifests are bare `[workspace]` + `resolver = "2"` + members — no
  `[workspace.dependencies]`/`[profile]` to reconcile. The desktop app pins its
  own dep versions (no `workspace = true` inheritance), so it is self-contained.
  The `air-rs` path-dep `../../../crates/air-rs` resolves identically in air-note
  (apps/desktop/src-tauri → up 3 → root → crates/air-rs).
- **npm workspace:** air-note has no root `package.json` today (`agent-bridge-mcp`
  is a standalone npm package). Add a new root `package.json` with workspaces
  `["apps/*", "packages/*"]`. This does NOT include `agent-bridge-mcp` (not under
  those globs), so the messaging stack stays independent and untouched.
- **README:** update to present both products (AIR Note messaging + BossClaw
  reference desktop app).
- **`.gitignore`:** ensure `node_modules/`, `target/`, `dist/`, `.env` are ignored
  (merge SuperClaw's entries that air-note lacks).

## Execution order (irreversible step is LAST)

1. **Branch** in air-note: `feat/import-bossclaw-desktop`. (done — this spec lives here)
2. **Copy** the files in; drop nothing from air-note; wire both workspaces + root config.
3. **Build + test locally** (no network-facing actions):
   - `cargo build` (workspace builds crate + desktop backend)
   - `cargo test -p air-rs` (crate conformance still green)
   - `npm install` at root, then `npm run typecheck` (desktop app) — confirm the
     workspace resolves `@bossclaw/shared`.
   - `cd agent-bridge-mcp && node --test` — prove messaging is untouched/green.
4. **Publish-safety gate:** print the exact list of files that would become public
   (`git status` / `git ls-files` on the branch) + re-run the secrets scan on the
   final tree. Peter eyeballs and approves.
5. **Push → PR → merge** to air-note `main`.
6. **Archive** `ahnkwangwook-oss/bossclaw` (read-only) with a final README commit
   pointing to air-note. Local `~/SuperClaw` left in place until Peter says otherwise.

## Publish-safety (air-note is PUBLIC)

- Secrets scan already run on SuperClaw's tracked tree: **no real secrets**. The
  only env file is `.env.example`; API keys are stored in the OS keychain via
  `src-tauri/src/secrets/` (macos/linux/windows). The grep hits were code
  identifiers (`openai_api_key` key *names*), not values.
- Re-run the scan on the final imported tree before the push (Step 4).
- The push is the one-way door: once public, content may be cached/indexed even if
  later removed. No push until the Step 4 gate passes.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| Publishing desktop source | Scanned clean; Step 4 file-list + secrets gate before push |
| Breaking the messaging build | `agent-bridge-mcp` never touched; run its tests anyway |
| Cargo workspace hiccup | Both manifests trivial; full `cargo build` before any push |
| npm workspace clash with agent-bridge-mcp | Root workspace globs exclude it; it stays standalone |
| Losing app history | Preserved in the archived SuperClaw repo |
| `.github` CI path breakage | air-note had no workflows; verify `conformance.yml` paths resolve to `crates/air-rs` (present) |

## Testing / verification

- Workspace `cargo build` + `cargo test -p air-rs` green.
- Desktop app `npm run typecheck` green with `@bossclaw/shared` resolved from the workspace.
- `agent-bridge-mcp` `node --test` suite still passes (regression proof).
- Optional: `cargo build` the desktop `src-tauri` target (full Tauri build is heavy;
  typecheck + cargo check may suffice for CI — decide in the plan).

## Decisions made

- **History:** clean import (one import commit); full history preserved in the
  archived SuperClaw repo.
- **Old repo fate:** archive `ahnkwangwook-oss/bossclaw` read-only with a redirect
  README; do NOT delete; keep local `~/SuperClaw` for now.

## Out of scope (YAGNI)

- Renaming the `air-note` repo.
- Publishing `air-rs` to crates.io.
- Folding `agent-bridge-mcp` into the npm workspace.
- Deleting `~/SuperClaw` locally.
- Reconciling/merging the two `.github` CI pipelines beyond carrying SuperClaw's over.
